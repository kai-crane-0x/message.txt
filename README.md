Initially, the primordial script is subjected to a metamorphosis so thoroughgoing that its erstwhile legibility is entirely forfeit, and it no longer answers to the description of language. Upon this transfigured residue there supervenes a clandestine perturbation, adjudicated by an arcanum purposely contrived to elude easy apprehension. Finally, the customary sequence of graphemes is subtly dislodged from its accustomed tenure, a tremor so slight that it scarcely merits remark. Nothing herein is recondite in itself; the sole imperative is to retain, without lapse, both the nature of each operation and the sequence in which they were enacted.
